# 🎓 Board Quiz

**CBSE Class 12 Mock Test Platform**  
*Practice smarter. Understand better. Score higher.*

Board Quiz is a student-focused online quiz platform designed for CBSE Class 12 students. It helps students practise Physics, Chemistry, and Mathematics through interactive mock tests, multilingual support, instant scoring, and answer explanations.

**Created by Maitrik Ghetiya**  
**Quad AI School of Technology**

---

## ✨ Features

- 📚 **Three Subjects:** Physics, Chemistry, and Mathematics.
- 🌐 **Multilingual Interface:** English, Gujarati, and Hindi.
- ⏱️ **Timed Mock Tests:** Practise under exam-like conditions.
- 📝 **Question Navigation:** Move between questions and review your answers.
- 🔖 **Mark for Review:** Flag questions to revisit before submitting.
- 📊 **Instant Results:** View your score after completing a test.
- 💡 **Answer Explanations:** Understand why an answer is correct.
- 📈 **Quiz History:** Review previous quiz attempts.
- 🧹 **Clear History:** Clear saved quiz history with a confirmation step.
- 💾 **Local Storage:** Save supported preferences and quiz history in your browser.
- 📱 **Responsive Design:** Use the platform on desktop, tablet, or mobile.
- 🎨 **Custom Branding:** Board Quiz branding with a Quad AI-inspired visual theme.

The question bank should be checked against the applicable **CBSE Class 12 syllabus for the 2026–27 academic session**. Verify questions and answer keys before relying on them for exam preparation.

## 🧮 Scoring System

| Response | Marks |
|---|---:|
| Correct answer | +4 |
| Incorrect answer | −1 |
| Unanswered question | 0 |

**Final Score = (Correct Answers × 4) − (Incorrect Answers × 1)**
